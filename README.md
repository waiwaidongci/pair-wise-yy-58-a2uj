# pair-wise-yy-58 大型构件吊装三维校核平台

围绕大型转换桁架夜间吊装复算，提供三维场景、时间轴校核、参数依赖驱动的冲突重算、条件评论、多角色会签与发布门禁。页面支持拖动旋转吊装场景、编辑步骤参数（荷载率 / 净空 / 风速 / 幅度 / 臂长）、处置规则冲突、断网保留现场修改、会签批次判重，并在失效项未清完前锁定发布入口。

## 夜间复算的四条核心规则

1. **参数依赖驱动的选择性失效**：每条规则、每条意见、每位复核人的签署都显式声明依赖的工况参数（`src/domain.ts`、`src/rules.ts`）。某个步骤参数一变：
   - 只重算依赖该参数的规则冲突，该冲突上的"现场处置"记录同步失效需重核；
   - 只让同一步骤上**未关闭**且依赖该参数的意见失效（已解决意见保持不动），可"按当前参数重新核对"退回未关闭；
   - 只让 `basis` 中记录了该参数的签署失效，卡片列出每个参数"签署时 → 当前"的差值，支持一键按当前版本重签；
   - 不相关步骤、意见与签署不受影响。
2. **断网按步骤合并、原请求可重试**：断网时修改按步骤进入现场队列（同步骤连续修改合并为一个请求，保留最早基准值）；联网后按步骤做三路合并（同步基准 / 服务端当前值 / 现场值）。同参数被他端修改时合并失败、**现场值保留**，可"保留现场值重试原请求"或以服务端当前值为新基准，也可"采用当前版本值"。
3. **同版本会签只收一次**：服务端按批次 `batchId` 幂等 + 批次内容指纹判重。两名复核人同时提交同一版本的同一批内容，先到的 accepted、后到的 duplicate；后到者本批内容保留、页面显示当前版本，批次记录里标明先提交人。版本已前移的批次返回 stale，提示基于当前版本重签。
4. **发布门禁**：冲突未清零（允许登记现场处置并经确认）、存在未关闭或失效待重核意见、四角色签署缺失 / 失效 / 同步中、队列里还有未合并或合并失败的请求、当前断网——任一不满足，顶部和会签页均展示红色退回原因，锁定按钮禁用。

## 代码结构

- `src/domain.ts`：步骤 / 意见 / 签署 / 队列请求模型，参数标签与批次指纹。
- `src/rules.ts`：规则引擎，每条规则声明 `deps`，冲突 id 为稳定的 `步骤:规则`。
- `src/sync.ts`：模拟协同服务端（独立 localStorage 持久化），在线状态、按步骤三路合并、会签批次判重、发布锁定、注入他端修改。
- `src/store.ts`：参数变更的唯一入口 `applyParamChanges`（选择性失效）、现场请求队列与重试、门禁原因 `gateReasons` 与就绪度。
- `src/App.vue`：三维复核 / 模型参数 / 冲突与评论 / 多角色会签四个页面，含网络开关、现场队列、合并冲突处置、并发会签演示。
- `scripts/smoke.ts`：Node 冒烟脚本，覆盖选择性失效、断网合并、合并失败重试、并发判重、门禁放行全链路。

```bash
npx esbuild scripts/smoke.ts --bundle --platform=node --format=cjs --outfile=/tmp/smoke.cjs && node /tmp/smoke.cjs
```

## 建议演示路径

1. 顶部切到"断网"，在模型页改 S-03 荷载率并保存 → 请求进入现场队列；
2. 恢复"在线" → 自动按步骤合并，版本号前移；
3. 断网改 S-01 荷载率保存 → 点检查器里"演示：他端在线改了…"（脚本冒烟用的是服务端直改 S-01）→ 恢复在线 → 看到合并失败、现场值保留，二选一处置；
4. 改 S-04 风速到 9.5 → 只出现风速冲突、周工类依赖失效，陈晓（不依赖风速）签署仍有效；改 S-02 净空 → C-11 意见失效、陈晓签署失效并显示差值；
5. 会签页点"演示：两人同版本同时提交（只收一次）"→ 一条 accepted 一条 duplicate；
6. 登记全部冲突处置、关闭 / 重核全部意见、四人签署齐全 → 门禁由红转绿，锁定发布 V+1。
7. 顶栏"重置演示"可清空本地与模拟服务端状态重来。

数据草稿与模拟服务端状态保存在浏览器 `localStorage`，Apollo 内存缓存保存已锁定方案版本快照。
